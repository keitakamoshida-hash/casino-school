# Casino School

スマホ・PC向けの独立したカジノ学習ゲーム。依存パッケージ不要、Node.js 22以降。

```sh
cd /Users/senjinpc116/casino-school
npm start
```

http://localhost:4173 を開く。テストは `npm test`。

## 収録ゲーム

- ポーカー：CPUとのヘッズアップ・テキサスホールデム。難易度3段階。初心者向けのアンティ＋各ストリート1回の固定額ベット（ブラインド・レイズ・オールイン・サイドポットは未対応）。CPUは自分の手札と公開カードだけを使い、標準・上級は仮想的な配札を試行して勝率を推定する。CPUの資金はハンドごとに補充。
- ブラックジャック：6デッキ、S17、ナチュラル3:2、ヒット・スタンド・ダブル。スプリット・保険・サレンダーは未対応。ヒントは簡易版。
- ルーレット：横画面向けのホイール＋ベットマット。チップをマウス・指でドラッグ、または金額を選んでタップ。数字・赤黒・奇偶・大小・列・ダズンに複数同時ベット可能。1枚戻す／全て戻す／前回と同じ配置に対応。枠線上のスプリット・コーナーは未対応。
- バカラ：8デッキ、標準の第三カードルール、Banker手数料5%、Tie 8:1。

毎日日本時間0時を境に1回、100,000コインを受け取れる。架空通貨のみで購入・換金はない。残高、進行中のゲーム、設定、直近12件の結果をlocalStorageに保存する。毎ハンド新しい山札をシャッフルし、乱数はWeb Cryptoと棄却法を使う。勝敗に応じた配札操作はない。

ローカル専用のため、ブラウザデータ削除や端末時計変更を防ぐ仕組み、アカウント・端末間同期・複数タブ同時プレイの整合性保証はない。同じブラウザの1タブで利用する。公開サービス向けの残高検証は未実装。


## カジノ体験・操作

- ルーレット：5.2秒かけてホイールとボールが減速。停止してから出目と配当を公開する。チップの配置時にコインを確保し、回転前の取り消しで返却。回転中は変更不可。選んだ出目は保存され、再読み込みしても引き直さない。
- バカラ：順番に配られたカードを、指で上方向へスライドして絞る。80px以上で公開、途中で離すと伏せ札に戻る。1枚ずつ開くボタンと一括公開も用意。最後のカードの公開後に配当を反映。
- ブラックジャック：初回配札、ヒット、ディーラーの伏せ札公開・追加ドローを時間差で表示。配当は演出終了後に反映。3:2の意味と実際の払戻額を併記。
- ポーカー：配札・共通カード・ショーダウンに待ち時間と公開演出を追加。
- スマホは横画面を推奨。縦画面でもマットを横スクロールして利用可能。演出中も進行・結果を保存する。動きを減らすOS設定に対応（ルーレットの待ち時間は維持）。

## 検証

`npm test` はルール・残高・保留ベット・回転中の再読み込み・カード公開までの配当保留を検証する。ブラウザでもマウス／タッチのドラッグ、キーボード配置、縦横表示、カード絞り、演出途中の再読み込みを確認。
