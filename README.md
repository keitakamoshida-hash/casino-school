# Casino School

スマホ・PC向けの独立したカジノ学習ゲーム。依存パッケージ不要、Node.js 22以降。

```sh
cd /Users/senjinpc116/casino-school
npm start
```

http://localhost:4173 を開く。テストは `npm test`。

## 収録ゲーム

- ポーカー：CPUとのヘッズアップ・テキサスホールデム。難易度3段階。初心者向けのアンティ＋各ストリート1回の固定額ベット（ブラインド・レイズ・オールイン・サイドポットは未対応）。CPUは自分の手札と公開カードだけを使い、標準・上級は仮想的な配札を試行して勝率を推定する。CPUの資金はハンドごとに補充。
- ブラックジャック：6デッキ、S17、ナチュラル3:2、ヒット・スタンド・ダブル。スプリット・保険・サレンダーは未対応。ヒントは簡易版。
- ルーレット：シングルゼロ。赤黒・奇偶・大小・ストレートアップ。
- バカラ：8デッキ、標準の第三カードルール、Banker手数料5%、Tie 8:1。

毎日日本時間0時を境に1回、100,000コインを受け取れる。架空通貨のみで購入・換金はない。残高、進行中のゲーム、設定、直近12件の結果をlocalStorageに保存する。毎ハンド新しい山札をシャッフルし、乱数はWeb Cryptoと棄却法を使う。勝敗に応じた配札操作はない。

ローカル専用のため、ブラウザデータ削除や端末時計変更を防ぐ仕組み、アカウント・端末間同期・複数タブ同時プレイの整合性保証はない。同じブラウザの1タブで利用する。公開サービス向けの残高検証は未実装。
